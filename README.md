# Салон красоты «Лианна» — сайт-визитка

Одностраничный сайт-визитка для салона красоты «Лианна» (г. Михайловск, ул. Ленина, 161/5).

## Что внутри

- **Герой-секция** с рейтингом 4.4 из 2ГИС и кнопкой звонка
- **Услуги**: волосы, ногти, брови
- **Цены** — прайс салона на стрижки (мужская, женская, детская, для пенсионеров)
- **О салоне** с фото интерьера, фактами и ссылкой на 2ГИС
- **Галерея работ** с лайтбоксом (5 фото: стрижки, укладки, свадебная причёска)
- **Контакты**: адрес, телефон, маршрут, карточка 2ГИС

## Технологии

Чистый HTML + CSS + JavaScript, без сборщиков и зависимостей.
Шрифты: Prata + Rubik (Google Fonts).
Палитра: бордо, золото, крем.

## Структура

```
├── index.html      — разметка
├── css/style.css   — стили и адаптив
├── js/main.js      — меню, анимации, лайтбокс
└── img/            — фото салона и работ
```

## Запуск

Просто откройте `index.html` в браузере, либо опубликуйте через GitHub Pages.

## Данные

Телефон, адрес, рейтинг и цены — из карточки 2ГИС (рейтинг 4.4, 19 отзывов) и прайса салона.
Фотографии — из карточки салона в 2ГИС.
